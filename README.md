# War of Dots — 보급과 철도

점(dot)으로 표현된 군대가 싸우는 미니멀 실시간 전략 게임입니다. **보급**과 **철도**가 핵심입니다.
철도로 병력을 순식간에 전선 뒤로 보내 거점을 장악하고, 적의 철도·보급창을 끊어 포위·섬멸하세요.

- 단일 파일: `index.html` (순수 JavaScript + Canvas 2D, 외부 라이브러리 없음)
- 실행: 브라우저로 `index.html`을 열고 난이도를 고른 뒤 **전쟁 시작**
- 승리: 적 수도 점령 · 패배: 아군 수도 함락

## 조작법

| 입력 | 동작 |
| --- | --- |
| 좌클릭 / 드래그 | 부대 선택 / 박스 선택 (Shift: 추가, 더블클릭: 화면 내 같은 종류) |
| 우클릭 | 이동. 출발·도착 지점 근처에 아군 철도역이 있으면 자동으로 열차 이동 |
| Shift+우클릭 / Alt+우클릭 | 웨이포인트 추가 / 도보 강제 |
| 거점 클릭 → Z · X · C | 보병 · 기계화 · 포병 생산 |
| R | 철도 건설 모드 (아군 거점 → 대상 거점 클릭) |
| S / T | 보급 오버레이 / 철도 오버레이 |
| Space · 1 · 2 · 3 | 일시정지 · 1x · 2x · 4x |
| 방향키 · 휠 · 휠 드래그 · 미니맵 | 카메라 |
| Q · F · Ctrl+A · M · H | 정지 · 선택 부대로 이동 · 전체 선택 · 소리 · 도움말 |

## 핵심 설계

- **보급**: 수도·보급창이 보급원이고, 연결된 도시가 재송출합니다. 거점 사이 전달은 도로(거리만큼 감쇠)와
  철도(거의 무손실)로 이루어지고, 이어서 격자 다익스트라로 주변 지형에 퍼집니다(도로는 싸고 산·강·적 영토는 비쌈).
  적 영향권이 우세한 셀은 보급을 받기만 하고 더 퍼뜨리지 못하므로, 완전히 둘러싸인 내부는 도달 불가 = **포위**입니다.
  상태: 보급 중 / 보급 부족(이동·공격 감소, 조직력 회복 중단) / 보급 차단(조직력·병력 지속 감소 → 항복).
- **철도**: 건설 비용·시간이 들고, 열차는 도로 속도의 7배입니다. 선로 구간마다 동시 수송 한도가 있어 혼잡하면 대기합니다.
  적 부대가 선로 위에 서면 구간이 끊겨 이동과 보급이 모두 막히고(수송 중이면 탈선), 적이 떠나면 자동 복구됩니다.
  거점을 점령하면 연결된 철도도 넘어오지만 궤간 전환 시간이 지나야 쓸 수 있습니다.
- **AI**: 같은 규칙(자원·생산·보급·철도)을 따릅니다. 주기적으로 위기 대응 → 생산 → 철도 건설 → 철도 증원 방어 →
  확장 → 공세(철도 집결 후 동시 공격, 전과 확대) → 기계화 포위 기동(철도·보급창·보급선 차단, 측면 우회) → 예비대 배치를 평가합니다.
  난이도는 판단 주기, 공세 기준·시점, 철도 활용도만 다릅니다(자원 보너스 없음).
- **밸런스**: 모든 수치는 파일 상단 `CONFIG` 객체에 모여 있습니다.

## 테스트용 디버그 API

브라우저 콘솔에서 `WOD.start(diff, seed)`, `WOD.step(seconds)`, `WOD.spawn(side, type, x, y)`,
`WOD.autoplay(diff)`(아군도 AI가 조종), `WOD.stats()` 등을 사용할 수 있습니다.
`index.html?autostart=1&diff=hard&seed=42&ai1=normal` 로 AI 대 AI 관전도 가능합니다.
