# 정글 — 동남아 정글 사실주의 전쟁 FPS (1단계 / 5단계)

열대 정글을 배경으로 한 사실주의 1인칭 전쟁 게임의 **1단계: 기술 기반 + 정글 맵 + 사실적 이동 시스템**입니다.
걷기만 해도 “무겁고, 지치고, 위험하다”는 느낌이 들도록 지형·지면·스태미나·소리를 만들었습니다.
무기·적·체력 시스템은 아직 없으며, 다음 단계가 붙을 자리만 마련되어 있습니다.

- Three.js + Vite, JavaScript (ES 모듈), 브라우저 실행
- 모델·텍스처·사운드 파일 없음 — 지형, 식생, 텍스처(캔버스), 소리(Web Audio)를 모두 코드로 생성

## 실행

Node.js 18 이상이 필요합니다 (Vite 8 기준 20.19+ 권장).

```bash
npm install
npm run dev        # http://localhost:5173 — 화면을 클릭하면 시작
```

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | 프로덕션 빌드 (`dist/`) |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run check` | **이동 규칙 헤드리스 검증** — 실제 맵 위에서 이동 컴포넌트를 돌려 지면별 속도·빠짐·미끄러짐·스태미나·거동 불능·점프·레이캐스트를 측정 |
| `npm run map` | 생성된 맵을 위에서 본 이미지(`map.png`)로 출력 |

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점 (지연 없이 즉각 반응) |
| Shift | 달리기 |
| X | 조용히 걷기 (토글) |
| C / Z | 앉기 / 엎드리기 (토글) |
| Q / E | 기울이기 (누르고 있는 동안) |
| Space | 점프 (앉은 상태에선 일어서기) |
| Esc | 일시정지·설정 (감도, FOV, 그래픽 품질, 시간대, 날씨, 음량) |
| F3 | 디버그 오버레이 — 켜진 동안 **숫자키 1~8로 테스트 지점 순간이동** |
| F6 | 거동 불능 시뮬레이션 (서기·앉기 불가, 포복만, 속도 50%) |

> F3·F6은 브라우저에 따라 가로채일 수 있어 Esc 메뉴에도 같은 체크박스를 두었습니다. Ctrl은 쓰지 않습니다.

### 테스트 지점 (F3 + 숫자키)

시작 지점 반경 150m 안에서 모든 지면 종류를 만날 수 있습니다.

1 시작/다져진 흙길 · 2 진흙 오솔길 · 3 늪 가장자리 · 4 주 논둑 · 5 개울 여울 · 6 코끼리풀 군락 · 7 젖은 급경사(개울 둑, 자동 탐색) · 8 대나무 숲

권장 확인 순서: 시작 지점의 오솔길을 따라 남서쪽으로 → 오솔길이 진흙으로 변함 → 늪 → 늪 동쪽 오솔길로 논 → 주 논둑(빠름·높음) vs 논 안(느림·빠짐) → 동쪽 개울 여울.
경사 미끄러짐은 Esc → 날씨 “폭우”로 바꾼 뒤 약 20초(젖음도 상승) 후 7번 지점에서 확인하세요. (게임 시작 전에 고른 날씨는 젖음도가 바로 적용됩니다.)

## 구현 내용

### 맵 (400m × 400m, 시드 고정)
- 언덕·능선(fBm + 릿지 노이즈)과 저지대 골짜기, 남북으로 흐르는 개울 2개 (대부분 발목~무릎, 웅덩이는 허리 깊이), 오솔길이 지나는 곳은 얕고 넓은 여울
- 저지대 늪 (깊은 진흙 + 고인 물웅덩이, 가장자리 얕은 진흙 → 젖은 흙)
- 5×4칸 논: 물 찬 논과 좁은 논둑(0.6m), 가운데 넓은 주 논둑. 논둑은 바닥보다 0.28~0.32m 높아 빠르지만 노출되고, 논 안은 느리고 25cm 빠짐
- 맵을 가로지르는 오솔길 6개 (저지대 구간은 자동으로 진흙화, 시작 오솔길은 명시적으로 흙길 → 진흙길)
- 쓰러진 통나무(일부는 점프해야 넘음), 바위, 드러난 큰 뿌리, 큰 나무의 판근 — 모두 높이를 가진 지지형 장애물
- 가장자리: 북·서 절벽(35° 이상 → 오를 수 없고 미끄러져 내려옴), 남 깊은 강(가슴 이상 → 진입 불가), 동 밀집 대나무 띠(통과 불가). 투명벽은 이 뒤에 숨긴 최후 안전 경계뿐
- 식생 층: 상층 큰 나무(판근·리아나·우산형 수관, 하늘 대부분을 가림) / 중층 야자수·바나나·대나무 군락 / 하층 고사리·덩굴덤불·코끼리풀 / 바닥 낙엽·부엽토 (지형 셰이더) / 논의 모
- 모든 오브젝트에 `blocksMovement`, `visionBlock`, `bulletBlock` 태그 (`src/config.js`의 `objects`)

### 분위기
- 캐노피 맵으로 숲 바닥의 직사광·하늘빛을 가림 → 어두운 바닥과 햇빛 틈의 대비, 틈 사이로 새는 빛줄기
- 높이 안개: 저지대(늪·논·골짜기)에 깔리는 안개 + 거리 안개
- 지형 스플랫 셰이더: 낙엽·흙길·진흙·풀·바위(급경사) 질감 혼합, 진흙·젖은 곳은 어둡고 번들거림
- 시간대 3종(새벽 안개 / 한낮 / 해질녘), 날씨 3종(맑음 / 비 / 폭우) — 비가 올수록 젖음도가 오르고 지면이 번들거림

### 이동 (사람 공용 컴포넌트 `HumanMotor`)
- `getSurfaceAt(x, z)`로 지면 판정 → 지면별 속도·스태미나·빠짐·가속도·발소리·소음 반경
- 진흙 규칙: 깊은 진흙·논에서 달리기·점프 불가, 가만히 서 있으면 3초에 걸쳐 최대 50cm까지 빠짐, 다시 움직이면 최대 0.8초 발 빼는 지연 + 빨아들이는 소리, 걸음 주기에 맞춘 속도 출렁임, 빠진 만큼 카메라 하강
- 깊은 물·깊은 진흙에선 엎드리기 불가, 가슴 이상 물은 진입 불가
- 경사: 15°부터 오르막 감속, 35° 이상 못 오름, 젖은 흙·진흙 25°(젖음도가 높을수록 낮아짐) 이상에서 미끄러짐, 달리면 더 크게
- 자세 3종 + 전환 시간, 기울이기(나무·지형에 막히면 덜 기울어짐), 낮은 점프
- 스태미나: 실제 변화 = 회복 − 소모 × 지면 배율 × 무게 배율 × 오르막 배율. 0이면 30까지 달리기 불가 + 거친 숨. 수치 바 없이 숨소리·비네트·카메라 호흡 흔들림으로만 표현
- 심박수(`motor.heartRate`)와 노출도(`motor.exposure`)를 외부에서 읽을 수 있음

### 소리 (Web Audio 절차 합성)
- 지면별 발소리 9종, 진흙 발 빼는 소리, 착지, 미끄러짐, 자세 전환
- 정글 환경음(매미·귀뚜라미·새 5종·긴팔원숭이·먼 울음·개구리·바람), 날씨 연동 빗소리·물방울, 스태미나 연동 숨소리·심장 박동
- 발소리마다 소음 이벤트(위치, 반경) 발생 → `NoiseEvents` (빗소리가 클수록 반경 감소). F3 상태에서 노란 원으로 표시

### 화면
- 조준점·체력·스태미나 바·미니맵 없음. 왼쪽 아래 흐린 자세 아이콘(아래 점 = 조용히 걷기)만 표시
- F3: FPS, 좌표, 지면, 빠진 깊이, 속도, 스태미나, 심박수, 소음 반경, 노출도, 시야/탄도 레이캐스트 결과 등

## 폴더 구조

```
src/
  config.js            ← 모든 조정 수치
  main.js
  core/                Game(루프·조립), Input, Settings, NoiseEvents, EventEmitter, rng, noise, math
  world/               WorldGen(순수 데이터 생성), MapLayout, WorldQuery(물리 질의·raycastWorld),
                       Surfaces, TreeVariants, World(렌더 조립), TerrainMesh, WaterMesh, Vegetation(인스턴싱)
  human/               HumanMotor(사람 공용 이동), Exposure(노출도)
  player/              PlayerController(입력→의도), CameraRig, BreathCycle
  render/              Atmosphere(하늘·빛·안개·비·빛줄기), Materials(셰이더 패치), Textures, VegetationGeometry, MeshBuilder
  audio/               AudioEngine, Footsteps, Ambience, Breathing
  ui/                  HUD, DebugOverlay, Menu, styles.css
scripts/               sim-check.mjs (헤드리스 검증), render-map.mjs, png.mjs
```

`world/WorldGen.js`, `world/WorldQuery.js`, `human/HumanMotor.js`는 three.js에 의존하지 않아 Node에서도 돌아갑니다 (`npm run check`).

## 다음 단계를 위한 연결점

- **2단계 무기**: `CONFIG.load.baseKg`에 무기 무게를 더하면 속도·스태미나에 반영. 조준 흔들림은 `motor.heartRate`, `motor.breath`, `BreathCycle.phase`를 사용
- **3단계 부상**: `motor.setRestriction(name, { canStand, canCrouch, canProne, canSprint, canJump, maxSpeedMultiplier })` / `clearRestriction(name)` (F6이 같은 API 사용)
- **4단계 적 AI**: 적 병사도 `new HumanMotor(world.query, {...})`로 같은 진흙·경사·스태미나 규칙을 받음. `noise.on('noise', …)` / `noise.audibleAt(x, z)`로 소리 감지, `world.query.raycastWorld(origin, dir, maxDist, 'vision' | 'bullet')`로 시야·탄도 판정, `motor.exposure`로 노출도
- 실제 에셋 교체: 텍스처는 `render/Textures.js`, 식생 모델은 `render/VegetationGeometry.js`, 소리는 `audio/*`의 합성 함수만 교체하면 됨

## 알려진 한계

- 맵 생성(약 1.3초)과 셰이더 컴파일 때문에 첫 로딩이 몇 초 걸립니다.
- 안티에일리어싱은 시작 시 품질로 정해집니다 (‘낮음’으로 시작하면 꺼짐, 바꾸려면 새로고침).
- 식생은 실루엣 위주의 저폴리 절차 모델이라 가까이서 보면 단순합니다. 수관 아래에서 보는 모습에 맞춰져 있습니다.
- 캐노피 그림자는 1m 해상도 캐노피 맵으로 근사하고, 그림자 맵은 플레이어 주변 줄기·하층 식생만 그립니다.
- 바위 충돌은 타원체 근사라 울퉁불퉁한 표면과 몇 cm 어긋날 수 있습니다.
- 통나무 넘기는 “점프 + 디딤” 방식입니다 (별도 넘기 동작 없음).
- 소리는 절차 합성이라 실제 녹음보다 단조롭습니다. 플레이어 발소리는 3D 위치 지정 없이 재생합니다 (4단계 적 발소리는 `Footsteps.play(evt, {pan, distance})`로 재사용 가능).
- 헤드리스 환경(소프트웨어 렌더링)에서 기능을 검증했으며, 실제 GPU에서의 프레임레이트는 사양에 따라 다릅니다.
