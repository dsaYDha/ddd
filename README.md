# 정글 — 동남아 정글 사실주의 전쟁 FPS (4단계 / 5단계)

열대 정글을 배경으로 한 사실주의 1인칭 전쟁 게임의 **1단계: 기술 기반 + 정글 맵 + 사실적 이동 시스템**과
그 보완판 **“정글 지형지물 사실감 + 숲 밀도 개선”**, **2단계: 무기 조작·탄도·제압**, **3단계: 부위별 피격·부상**, 그리고 **4단계: 적 AI + 소리 정보** 입니다.
걷기만 해도 “무겁고, 지치고, 위험하다”는 느낌이 들도록 지형·지면·스태미나·소리를 만들었고,
어느 쪽을 봐도 식물로 가득 찬 울창한 정글이 되도록 식생·나무·빛을 다시 만들었습니다.
2단계에서는 “맞히기가 매우 어렵다”는 소총 사격(조준점 없음, 호흡 흔들림, 높은 반동, 실제 투사체 탄도)과
총알이 스치면 겁이 나는 ‘제압’의 기반을 더했습니다. 3단계에서는 “한 발 맞으면 끝”이라는 공포 — 급소는 즉사, 그 밖의 부위도
한 발이면 정상 기동이 불가능한 부위별 부상·출혈·자가 처치를 플레이어와 사람 개체(F8 표적 → 4단계 적)에게 같은 규칙으로 넣었습니다.
4단계에서는 “사람 같은 적” — 숨어서 먼저 쏘고, 분대로 협력하고, 겁먹고, 실수하고, 다치면 고통스러워하는 적 병사를 넣었습니다.
적도 플레이어와 같은 이동·사격·제압·부상 규칙을 따르며(AI 예외 없음), “보이는 것보다 들리는 것이 더 많은” 정글 전투가 되도록
모든 위치 소리를 HRTF 3D 음향으로 바꾸고 동물 소리의 정적을 단서로 만들었습니다.

- Three.js + Vite, JavaScript (ES 모듈), 브라우저 실행
- 모델·텍스처·사운드 파일 없음 — 지형, 식생, 텍스처(캔버스·픽셀 계산), 소리(Web Audio)를 모두 코드로 생성

## 실행

Node.js 18 이상이 필요합니다 (Vite 8 기준 20.19+ 권장).

```bash
npm install
npm run dev        # http://localhost:5173 — 화면을 클릭하면 시작
```

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | 프로덕션 빌드 (`dist/`) |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run check` | **헤드리스 검증** — 실제 맵 위에서 이동 컴포넌트를 돌려 지면별 속도·빠짐·미끄러짐·스태미나·거동 불능·점프·레이캐스트, 식생 지면 저항·바스락 소음·숲속 시야 거리·엎드림 은폐·덩굴 벽을 측정 |
| `npm run ai` | **적 AI 로직 검증 (4단계)** — 발견 시간·소리 추정 오차·제압 중 발사 0·사기 하락 후퇴/분대장 사망 혼란·부상자 행동·명중률·반응 지연·측면 우회·매복·수색·동물 정적·성능 예산 (렌더링 없음, 45개) |
| `npm run injury` | **부상 로직 검증 (3단계)** — 치명 4곳·실제 탄도 명중 분포·부위별 이동/사격 제한·출혈 시간·붕대/지혈대·저속/스침 예외·누적·사람 개체 반응 (렌더링 없음) |
| `npm run aim` | **난이도 자동 측정 (2단계)** — 가상 사수가 조건마다 1,000발을 쏴 명중률을 기준 범위와 비교 (`seed=N`, `seeds=1,2,3`, `rounds=N`, `info=0`, `only=2,3`) |
| `npm run map` | 생성된 맵을 위에서 본 이미지(`map.png`)로 출력 |
| `npm run build:single` | 게임 전체를 HTML 파일 하나(`dist/jungle.html`)로 묶음 — 서버 없이 더블클릭으로 열 수 있음 |

마우스 잠금(포인터 락)을 쓸 수 없는 환경에서는 자동으로 **마우스를 누른 채 끌어서 시점을 돌리는 방식**으로 바뀝니다 (Esc로 메뉴).
처음 실행했을 때 프레임이 계속 낮으면 그래픽 품질을 한 단계 자동으로 낮추고 알려 줍니다 (`config.performance`).

### 테스트 지점 (F3 + 숫자키)

시작 지점 반경 150m 안에서 모든 지면 종류를 만날 수 있습니다.

1 시작/다져진 흙길 · 2 진흙 오솔길 · 3 늪 가장자리 · 4 주 논둑 · 5 개울 여울 · 6 코끼리풀 군락 · 7 젖은 급경사(개울 둑, 자동 탐색) · 8 대나무 숲 · 9 울창한 숲속(덤불)
(순간이동하면 해당 지형을 바라보도록 방향도 맞춰집니다.)

권장 확인 순서: 시작 지점의 오솔길을 따라 남서쪽으로 → 오솔길이 진흙으로 변함 → 늪 → 늪 동쪽 오솔길로 논 → 주 논둑(빠름·높음) vs 논 안(느림·빠짐) → 동쪽 개울 여울.
경사 미끄러짐은 Esc → 날씨 “폭우”로 바꾼 뒤 약 20초(젖음도 상승) 후 7번 지점에서 확인하세요. (게임 시작 전에 고른 날씨는 젖음도가 바로 적용됩니다.)
오솔길을 벗어나 9번 지점 같은 숲속으로 들어가면 느려지고 걸음마다 바스락거립니다 (F3의 노란 원 = 소음 반경).

## 4단계: 적 AI + 소리 정보 (이번 변경)

적 병사 = 3단계 사람 개체(`HumanEntity`: 1단계 `HumanMotor` + 3단계 `Injuries` + 부위 캡슐) + 2단계 `Shooter` + AI 두뇌(`ai/Soldier.js`).
AI 는 입력(이동 의도·자세·시선·방아쇠·재장전)만 넣고, 진흙·경사·스태미나, 흔들림·반동·제압, 부위별 부상 제한은 플레이어와 같은 컴포넌트가 정합니다.
`ai/` 모듈은 three.js·DOM 없이 Node 에서 돌아갑니다 (`npm run ai`).

### 병사·무기 (`CONFIG.weapons.rifle556 / lmg762`, `render/SoldierMesh.js`)
- 모습: 판정 캡슐과 같은 캡슐 몸 + 정글 위장복(국소 좌표 3D 잡음 셰이더 — 짙은 녹색·갈색·검은 줄), 천 모자(부니햇), 탄띠·탄입대·수통·멜빵, 손 위치에 맞춘 소총/경기관총. 국적 표지·깃발 없음.
  병사마다 6가지 변형(군복 바탕색·무늬 시드·피부색·모자 무늬·팔다리 굵기 ±6%) — 지오메트리는 (변형, 무기, 자세)로 캐시해 공유.
- 적 소총(5.56, 760발/분, 높고 짧은 총성)·분대 경기관총(7.62, 650발/분, 100발 탄통, 엎드려 양각대 거치 시 근접 통과 제압 ×1.35×1.3, 낮고 무거운 총성).
  탄은 유한하고 재장전 중에는 못 쏨. 같은 편 근접 통과 제압은 ×0.25 (아군 탄에 묶여 버리지 않게).

### 감지 (`CONFIG.ai.vision / hearing / memory`, `ai/Perception.js`)
- 시각: 시야 120°(중앙 60° 밖은 ×0.4), `raycastWorld('vision')` 투과율(식생 높이 구간·visionBlock). 발견 수치가 시간에 따라 쌓여 1 에 닿으면 발견 (화면엔 안 보임).
  속도 = 기준 × 거리(30m 기준, 지수 1.6) × 1단계 노출도(자세·식생·빛) × 투과율 × 움직임(최대 ×3.6) × 주변시 × 상태(순찰 0.75 ~ 교전 1.4) × 개인차 × (1 − 제압 감쇠). 6m 안은 잎에 가려도 약간 감지(숨소리·흔들리는 풀).
  레이캐스트는 프레임당 8개 예산 안에서 병사들을 돌아가며 갱신.
- 사격하면 노출: 시야 안이고 총구가 조금이라도 보이면 즉시 발견 (정확한 위치).
- 청각: 1·2단계 소음 이벤트(발소리·바스락·자세·진흙·총성·착탄·장전). 추정 위치 오차 = 거리 × 15%(방향 무작위), 총성은 거리/음속 뒤에 들림(330m 밖 분대도 경계).
  근접 탄('딱') 직후 1.2초 안의 총성은 방향을 ±45°, 거리를 ±40% 헷갈림.
- 상태: 순찰 → 의심(조사) → 경계 → 교전 → 수색 → (1~3분 뒤) 경계 수준이 높아진 순찰(감지 ×1.35). 마지막 확인 위치를 기억하고 시간이 갈수록 불확실해짐.

### 분대 (`CONFIG.ai.squad / cover / search`, `ai/Squad.js`, `ai/NavGrid.js`)
- 3~6명 + 분대장, 오솔길을 따라 5~10m 간격 일렬, 첨병이 앞장 — 진흙·논에서는 1단계 규칙대로 모두 느려짐. 넘을 수 있는 통나무는 점프.
- 길찾기: 2m 격자 A* (지형 경사·물·식생 속도 비용, 큰 줄기·대나무 숲·덩굴 벽 막힘). 평소엔 오솔길 선호, 교전 중엔 은폐가 짙은 길 선호.
- 엄폐: 마지막 위협 방향을 막는 줄기·통나무·바위(총알을 막음)를 먼저, 덤불(은폐만)은 그다음. 숨는 점·내다보는 점을 따로 고름.
- 사격·기동: 교전이 시작되면 4명 이상인 분대는 뒤쪽 소총수 1~3명이 기동조 — 위협 기준 70~100° 측면, 18~28m 지점까지 숨을 수 있는 길로 돌아감(측면에 45° 이상 돌아가기 전에는 멈추지 않음, 최대 35초).
  나머지는 사격조 — 안 보여도 마지막 확인 위치 주변으로 제압 사격(플레이어도 2단계 제압을 받음). 기동조가 돌아가는 동안엔 접촉을 잃어도 수색으로 넘어가지 않음.
- 의사소통: 짧은 고함(발견·사격·측면·엄폐·부상자·혼란·후퇴 — 실제 언어가 아닌 외침 음절, 85m 까지 들리는 소음 이벤트) — 플레이어에게도 들려 위치 단서.
- 아군 사선: 사선 1.1m 안에 아군이 있으면 쏘지 않음 (8% 는 확인을 빼먹음).
- 수색: 접촉을 잃으면 2인 1조로 마지막 위치에 조심스럽게 접근, 가끔 수상한 덤불에 위력 수색 사격, 1~3분 뒤 포기.

### 사람다운 실수 (`CONFIG.ai.reaction / aim / fire`)
- 반응 지연: 발견 후 0.8~1.5초(놀람) / 0.3~0.7초(이미 경계). 조준은 반응이 끝난 뒤 0.5~2초에 걸쳐 안정 → 발견 직후 첫발은 오차 1.4° 를 남긴 채 서둘러 쏴서 자주 빗나감.
  그다음은 거리에 맞춰 ‘맞았다’ 싶을 때(오차 < 14°·m / 거리) 쏨 + 남는 느린 손떨림 0.5° + 2단계 흔들림·반동.
- 연발 2~4발(15m 안 4~8발, 기관총 5~10발), 놀라거나 제압당하면 조준 없는 공황 사격, 움직이는 표적 앞 겨누기는 불완전(×0.35~1.15).

### 제압·부상·사기 (`CONFIG.ai.suppression / wounded / squad.morale`)
- 제압 30 이상: 정확도↓·낮은 자세 / 60 이상: 엄폐물 뒤로 숨고 사격 0 (발사 차단은 매 프레임 지금 수치로) / 85 이상: 완전히 웅크림, 은폐된 길이 있으면 가끔 뒤로 기어감 /
  45 이하로 내려가야 잠깐 내다본 뒤 다시 사격. 엄폐 없이 제압당하면 바로 엎드려 가장 가까운 엄폐물로 기어감.
- 부상: 3단계와 같은 부위 제한. 팔이 멀쩡하면 엎드린 채 계속 사격, 비명·도움 요청(소음 이벤트), 엄폐물로 기어가 플레이어와 같은 규칙·수량으로 붕대·지혈대.
  제압이 낮으면 동료가 부상자를 끌고 감 (0.6m/s — 둘 다 노출).
- 사기: 사상자·오래 제압·분대장 사망으로 떨어지고 수적 우세면 오름. 35 미만 → 엄호하며 단계적 후퇴(부상자 데리고), 15 미만 → 흩어져 도주.
  분대장 사망 → 3~6초 혼란 후 협력 약화 (고함 전달이 25m 밖에선 50% 빠짐, 기동조 없음).

### 매복 (`CONFIG.ai.ambush`)
- 분대장은 덤불 뒤 관측자(웅크림 — 접근로를 봄), 나머지는 오솔길 2~8m 옆에 엎드려 위장하거나 구덩이에서 머리·어깨만 내놓음(눈높이 약 0.65m — 풀 바닥층 위로 겨우 내다봄).
  자리는 그 자세 눈높이에서 kill zone 이 실제로 보이는(시야 투과율) 곳을 고름.
- 플레이어가 15~25m(무작위) 안에 들어와 보이거나 바로 옆에서 발소리가 들리면, 또는 들키면(맞거나 근접 탄) 0.15~0.45초 안에 동시에 사격.
  사상자가 나거나 사기가 떨어지면 숲으로 흩어져 후퇴 (치고 빠지기).

### 소리 정보 (`audio/AudioEngine.js` HRTF, `audio/Ambience.js`, `ai/Wildlife.js`, `CONFIG.audio.enemy`, `CONFIG.wildlife`)
- 위치가 있는 모든 소리(적 총성·탄 스침 ‘딱’·착탄·적 발소리·바스락·탄창 교환·고함·신음·쓰러짐·새·개구리)는 HRTF 3D — 앞뒤·위아래가 구분됨.
- 총성 거리감: 가까우면 날카롭고 크게(25m 안 고역 ‘짝’), 멀면 둔하고 낮게. 사이에 식생이 빽빽하면(시야 투과율) 더 작고 어둡게. 적 소총·기관총·내 소총 소리가 서로 다름.
- 동물 정적: 움직이는 사람(적·플레이어) 주변 36m 는 새·벌레가 잦아들고 조용히 20~40초 지나면 살아남. 총성 뒤 그 일대 30~90초 정적 (가까울수록 김).
  벌레 합창은 동서남북 네 방향으로 나뉘어 그쪽 활동도만큼 크게 들리므로 — 한쪽이 갑자기 조용해지면 그쪽에 누가 있음. 새는 활동도가 살아 있는 곳에서만 나무 위에서 운다.

### 테스트 도구
- **F4** 적 생성 메뉴 (최대 활동 16명 — 넘으면 잘라서 생성) · **F2** AI 디버그 시각화 · **F9** 무적 켜기/끄기 · F3 에 적 수·분대 상태·레이/프레임·AI 시간·동물 활동도.
- 성능 구조: 활동 적 최대 16명, 시야 레이 프레임당 8개(병사 순환), A* 프레임당 1개(탐색 노드 상한), 판단 병사마다 초당 6~9회(엇갈림), 매 프레임은 조종·조준·방아쇠만.

## 3단계: 부위별 피격·부상

목표는 “한 발 맞으면 끝”이라는 공포입니다. 급소는 즉사, 그 밖의 부위도 한 발이면 정상 기동이 안 됩니다.
플레이어와 사람 개체(F8 표적, 4단계 적 병사)가 **같은 부상 컴포넌트**(`combat/Injuries.js`)로 같은 규칙을 받습니다.

### 판정 (`CONFIG.injury`, `combat/Injuries.js` `classifyHit`)
- **치명 (즉사)**: 머리 전체, 목 전체, 가슴 상부 캡슐 안의 **심장·대혈관** (중앙 앞쪽 지름 13cm 구), **상부 척추** (등 쪽 중앙선, 목 아래~견갑골 사이).
  심장·척추는 탄이 들어간 점에서 진행 방향으로 0.45m 경로가 구·선을 지나는지로 판정 — 정면 가슴 상부 명중의 약 30%, 등 중앙선 명중은 대부분 치명.
  옆에서 상완을 뚫고 가슴으로 들어간 탄도 같은 판정 (`injury.pathParts`).
- **비치명**: 가슴(폐, 치명 구역 밖), 복부, 골반, 팔(상완·하완 좌우), 다리(대퇴·하퇴 좌우).
- **저속 탄**: 2단계 관통·도탄 뒤 남은 속도 비율(탄도에서 `projectile.retained`)이 40% 미만이면 한 단계 약하게 — 치명 → 가슴 수준 중상, 비치명 → 스침.
- **스침**: 탄 경로가 판정 표면에서 2cm 안쪽까지만 들어감 (또는 머리·몸통 표면 바깥 2cm 안을 지나감) — 경직 2초, 흔들림 ×1.3(영구), 출혈 1%/분, 이동 제한 없음.
  (팔 캡슐 반경이 5cm라 팔 명중의 절반 이상이 스침이 됩니다 — 사양 그대로.)

### 부위별 효과 (`injury.wounds`) — 가장 심한 제한 적용, 출혈은 더함, 치유 없음
| 부위 | 이동 | 사격 | 출혈 (%/분) |
| --- | --- | --- | --- |
| 가슴(폐) | 강제로 쓰러짐, 서기·앉기 불가, 기기 0.15m/s, 스태미나 상한 30, 기침·거친 숨 | 흔들림 ×2 | 12 |
| 복부·골반 | 강제로 쓰러짐, 서기·앉기 불가, 기기 0.15m/s | 엎드려 사격 가능, 흔들림 ×2 | 8 |
| 대퇴 | 강제로 넘어짐, 서기·걷기 불가, 앉기 가능, 기기·끌기 0.25m/s | — | 5 (25% 대퇴동맥: 30) |
| 하퇴 | 달리기·점프 불가, 서서 0.3m/s 절뚝이며 3~5걸음마다 휘청, 앉기·엎드리기 가능 | — | 3 |

  스태미나 상한 `maxStamina`·강제 자세 `forceStance` 추가)와 2단계 무기 배율(`aim.setExternal('injury', …)`, `weapon.actionTimeMul / fireDelay / setAutoBlocked`)로 겁니다.

### 혈액량·자가 처치
- 혈액 100%에서 상처마다 출혈(%/분)을 더해 줄어듦. **80% 미만** 심박·흔들림 증가, **60% 미만** 화면 회색·흐림·소리가 멀어짐·기는 속도 감소, **40% 미만** 의식 상실 → 사망.
  동맥 출혈은 1~2분(대퇴 30%/분 = 2분, 상완 25%/분 = 2.4분), 몸통은 수 분(가슴 5분, 복부 7.5분).
- **H 붕대** (2개): 7초 동안 멈춰서 감음 → 일반 출혈 ×0.15, 동맥 출혈은 ×0.6까지만.
- **G 지혈대** (1개): 5초 → 팔다리 출혈 정지 (그 팔다리는 계속 못 씀, 몸통 불가).
- 팔을 다쳤으면 처치 시간 ×1.5. 움직이거나 맞으면 취소 (물자는 다 감았을 때만 소모).

### 플레이어 표현 (체력 바·아이콘 없음)
- 맞으면 화면 충격(맞은 방향으로 머리가 젖혀짐 + 어두운 붉은 번쩍임), 이명 3초(세상 소리가 먹먹해짐), 순간 흐림, 몸 안에서 울리는 둔탁한 소리와 신음.
- 강제로 쓰러지면 시점이 땅으로 떨어지며 기울고, 쓰러져 있는 동안 기운 채 유지.
- 다치면 심박 상승(심장 소리·흔들림), 터널 시야, 아파서 앓는 숨 (가슴 부상은 쌕쌕·그르렁, 기침). 발밑에 어두운 핏자국.
- 사망: 시점이 땅에 쓰러지고 검게 꺼진 뒤 사망 화면 — 원인(“머리 관통”, “심장 관통”, “척추 손상”, “목 관통”, “출혈”)·생존 시간·Enter 다시 시작.
- 남을 맞혀도 히트마커 없음 — 쓰러지는 모습만 보고 판단.

### 사람 개체 (`combat/HumanEntity.js` — F8 표적이 4단계 적의 바탕)
- 1단계 `HumanMotor` + 3단계 `Injuries` + 2단계 판정 캡슐. 걷는 표적도 이동 컴포넌트로 걷습니다.
- **치명**: 맞은 방향으로 쓰러져 지형 경사에 맞춰 눕습니다 (발을 축으로 회전, 물리 없음 — 판정 캡슐도 같은 회전, `pose.fall`). 앉거나 엎드려 있었으면 그 자리에 늘어짐.
- **비치명**: 부위대로 쓰러지거나(가슴·복부·골반·대퇴) 주저앉고(하퇴·팔·스침), 충격이 풀리면 가장 가까운 엄폐물(총알을 막는 줄기·바위·통나무) 뒤로 3~5m 기어감.
  신음·거친 숨·기침, 출혈로 사망. 피는 작은 튐과 땅의 어두운 얼룩뿐 (고어 없음).
- 상태 읽기 (4단계): `entity.state` (`idle|walk|turn|stunned|crawl|down|dead`), `entity.injuries.summary()` (혈액·출혈·상처 목록·쓰러짐·총), `entity.motor.getState()`.

### 테스트 도구
- **F9**: 부위별 피격 메뉴 — 머리·목·심장·척추(치명), 폐·복부·골반·팔·다리, 동맥 고정, 저속 탄(심장 → 가슴 중상 / 대퇴 → 스침), 스침, 부상 초기화.
  지금 자세의 판정 캡슐에 실제 탄과 같은 명중을 만들어 같은 판정·효과 경로를 탑니다 (`game.testHit(kind, opts)`).
- **F6**: 대퇴 부상. **F3**: 상처 목록(부위·종류·동맥·붕대/지혈대·출혈), 출혈 속도, 혈액량, 의식 단계, 남은 붕대·지혈대, 충격·처치·총 상태, 이동 제한(자세별 최대 속도)과 사격 배율.
- **`npm run injury`**: 렌더링 없이 판정·출혈 시간·처치·누적·사람 개체 반응을 검사 (아래 결과).

### 소리 (`audio/InjuryAudio.js`, 절차 합성)
- 내 몸에 맞음: 낮은 쿵 + 갈비뼈 울림 + 신음, 이명. 사람 개체: 둔탁한 몸 착탄음(2단계), 신음(성대 톱니파 + 모음 포먼트), 거친 숨, 기침, 쓰러지는 소리 — 거리·방향·숲 흡수.
- 붕대: 포장 뜯기 → 천 감는 소리. 지혈대: 찍찍이 → 끈 당김 → 막대 돌리는 딸깍 + 신음.

## 2단계: 무기·조준·탄도·제압

목표는 “맞히기가 매우 어렵다”입니다. 아무렇게나 쏘면 거의 안 맞고, 자세를 낮추고 숨을 고르고 몸을 기대고 반동을 직접 잡아야 겨우 맞습니다.
총알이 근처를 스치면 겁이 나서 제대로 쏘기 힘들어지는 ‘제압’의 기반도 들어갔습니다.

### 무기 (데이터 기반 — `CONFIG.weapons`)
- 7.62mm 돌격소총 1종: 30발 탄창, 분당 600발, 3.9kg, 초속 715m/s, 영점 100m, 고유 산포 4.5 MOA. 예광탄은 꺼져 있음 (`tracer: true`로 켬).
- 탄창 6개(장전 1 + 예비 5)를 하나씩 따로 셈. 쓰다 만 탄창도 주머니로 돌아가 다시 쓰며, R은 가장 많이 남은 탄창을 꺼냄. 시작은 약실 1 + 탄창 29발(전체 180발).
- 무기·탄창 무게(약 8.8kg, 쏠수록 가벼워짐)가 1단계 장비 무게 25kg에 더해져 속도·스태미나에 반영.
- 단발 / 연발 (B). 재장전: 탄이 남았으면 2.3초(약실 1발 유지 → 31발), 비었으면 노리쇠까지 3.0초. 탄창 확인(T): 1.5초 동안 손으로 무게를 가늠한 뒤 네 단계 표시만.
- 기능 고장: 발당 0.05%, 오염도(0~100)에 비례해 최대 ×20. 진흙·논에서 엎드려 기거나 총이 물에 잠기면 오염. 고장 나면 방아쇠는 ‘딸깍’뿐 — R로 노리쇠를 당겨 해결(1.5초, 불발탄 1발 버림).
- 무기를 추가하려면 같은 형식의 항목을 하나 더 만들고 `weapons.default`를 바꾸면 됩니다 (코드 수정 없음).

### 조준을 어렵게 만드는 것 (`CONFIG.aim`, `combat/AimModel.js`)
- **조준점 없음.** 우클릭을 누르고 있는 동안 가늠자·가늠쇠로 조준 (전환 0.35초, 달리기 직후엔 0.5초 지연 동안 조준·사격 불가, 스코프 없음).
  1인칭 소총의 가늠자 홈과 가늠쇠 끝이 실제 조준선 위에 정확히 놓이므로 가늠쇠 끝이 곧 탄이 가는 곳입니다 (영점 100m).
- **비조준(지향) 사격**: 총구 방향 + 퍼짐(원뿔 반각) 서기 3.5° / 앉기 2.5° / 엎드리기 1.5°, 이동 중 최대 ×2.
- **조준 흔들림**: 호흡 8자 궤적(세로 = 호흡 주기, 가로 = 두 배) + 느린 표류 + 손떨림 + 방아쇠 흔들림. 기본 진폭 서기 1.0° / 앉기 0.6° / 엎드리기 0.3° / 거치 0.15°.
  심박 70 → ×1.0 … 170 → ×2.5, 스태미나 60 아래에서 추가(0이면 ×1.6), 조준 중 이동 1m/s당 +80% (조준 중 이동 속도 ×0.5).
- **숨 참기** (조준 중 Shift): 4초 동안 ×0.3 → 이후 3초간 ×1.8 + 스태미나 −15, 5초간 다시 숨 참기 불가 (일찍 놓으면 비례해서, 최소 40%).
- **무기 관성**: 시선을 돌리면 총이 감쇠 스프링으로 늦게 따라오고, 빠르게 돌리면 지나쳤다 돌아옴 (10°를 휙 돌리면 약 24% 넘쳤다가 0.6초에 멈춤).
- **거치**: 조준 중 총몸 아래(통나무·바위·뿌리·판근·논둑·흙둔덕)나 옆(나무 줄기·대나무)에 받칠 곳이 있으면 자동. 흔들림 0.15°, 반동 ×0.45. 아이콘 없이 총이 살짝 내려앉는 것으로만 표현.
- **반동**: 발당 수직 1.8°(±0.3) + 수평 ±0.9°가 시선을 직접 밀어 올림. 자동 회복은 40%뿐 — 나머지 60%는 마우스로 끌어내려야 함.
  연발하면 수직 반동이 5발째까지 ×1.0 → ×1.6. 자세 배율 1.0 / 0.75 / 0.5, 거치 0.45. 총이 화면에서 뒤로 튀고, 총구 화염이 순간 가늠쇠를 가리며, 습한 공기에 총구 연기가 1.5~3초 남음.
- **3단계 연결**: `game.shooter.aim.setExternal('팔 부상', { swayMul, recoilMul })` / `clearExternal(name)`로 흔들림·반동 배율을 밖에서 걸 수 있음.

### 탄도 — 실제 투사체 (`CONFIG.ballistics`, `combat/Ballistics.js`, `combat/BulletWorld.js`)
- 중력 + 공기 저항(dv/dt = −k·v²)을 1/240초 이하 간격으로 적분. 100m 0.150초·620m/s, 200m 0.324초(조준선 아래 20cm), 300m 0.523초(74cm 아래) — 100m 너머는 비행시간과 낙차가 보입니다.
- 관통은 1단계 `bulletBlock` 태그 그대로:
  none(풀잎·덤불·수관) 통과하되 빽빽한 잎을 지나면 0~1° 빗나갈 수 있음 / partial(대나무·덩굴 벽·나무고사리 줄기·리아나) 속도가 크게 줄고 1~5° 굴절 /
  full(큰 줄기·판근·통나무·바위·흙·논둑) 막힘. 물에 들어가면 크게 감속(얕은 각이면 튕김), 바위에 얕은 각으로 맞으면 도탄.
- 착탄 효과 (`render/CombatFX.js`, 그리기 호출 +4 이하): 흙 튐·흙먼지, 낙엽 바닥은 잎 조각, 나무 파편 + 탄흔, 물보라 + 물결, 진흙 덩어리 + 얼룩, 바위 먼지·불꽃, 대나무 섬유.
  빽빽한 잎을 지나면 잎 조각이 떨어집니다.

### 제압 — 사람 공용 컴포넌트 (`CONFIG.suppression`, `combat/Suppression.js`)
- 모든 사람(플레이어, 4단계 적 병사)이 제압 수치 0~100을 가짐. 매 프레임 탄의 이동 구간과 머리·몸통 캡슐 사이 최단 거리를 계산해,
  맞지 않고 2m 안을 지나면 ‘근접 통과’: 0.3m 이하 +30, 1m +15, 2m +5 (사이는 선형). 2m 안 착탄 +10. 마지막 이벤트 2초 뒤부터 초당 12씩 감소.
  30 경미 / 60 강함 / 85 완전 제압.
- 플레이어 효과: 지나가는 순간 짧은 화면 흔들림(가까울수록 큼) + 초음속 ‘딱’ 소리(발사음보다 먼저 들려 어디서 쏘는지 헷갈림).
  수치에 비례해 조준 흔들림 최대 ×2.5 + 미세 떨림, 심박 상승(숨소리·흔들림과 연동), 화면 가장자리가 어둡고 흐려지는 터널 시야, 주변 소리 먹먹함.
- 4단계 연결: `person.suppression.value / level`, 이벤트 `'nearPass' · 'nearImpact' · 'level'`, `game.combat.on('nearPass' | 'flyby' | 'hit' | 'impact', …)`.

### 지형지물 사실감
- **나무 줄기**: 여러 고리로 이어진 곡면 — 휘어짐, 둘레·높이 방향 노이즈 혹, 밑동 퍼짐, 아래쪽 세로 골. 형태별 껍질 색조
- **판근**: 줄기에서 뻗는 두꺼운 날개 — 위 모서리는 둥글고 아래로 갈수록 오목하게 넓어져 땅으로, 줄기 쪽은 크게 퍼져 줄기와 합쳐짐, 위로 갈수록 비틀림. 물리 판근(밟고 올라서는 지지면)과 같은 능선 식(`TreeVariants.finRidge`)
- **나무껍질**: 절차 텍스처(세로 갈라짐·판 모양 껍질·가로 균열·지의류 얼룩) + 같은 높이장으로 만든 법선 맵, 밑동·판근 사이·윗면은 이끼(셰이더), 밑동은 어둡게
- **가지 구조**: 줄기 → 큰 가지 → 잔가지 → 가지 끝마다 잎 덩어리 무리 (수관이 덩어리진 실루엣)
- **잎**: 캔버스로 그린 잎 덩어리 아틀라스 2048×1024(잎맥·장마다 다른 색·벌레 구멍·갈변), 교차 카드 + 둥근 법선으로 부피감, 양면, 역광 투과, `alphaTest` + `alphaToCoverage`(MSAA), 먼 거리에서 밉맵 알파가 줄어 숲이 성겨지지 않도록 밉 단계별 알파 보정
- **쓰러진 통나무**: 원통(울퉁불퉁) + 군데군데 벗겨진 껍질(목재 텍스처) + 쪼개진 마구리 나이테 + 부러진 가지 그루터기 + 윗면 이끼 + 선반 버섯·작은 버섯, 반쯤 묻힘
- **바위**: 영역 왜곡 노이즈로 깎은 불규칙한 덩어리, 절리면, 아래는 묻힘, 월드 좌표 삼면 투영 질감 + 윗면 이끼
- **지형**: 미세 요철 + 물방울 침식 시뮬레이션으로 날카로운 골짜기, 드러난 뿌리. 평지는 지피식물로 덮이고 28°~42° 사면은 흙이 줄무늬로 드러나며 42° 넘으면 바위. 줄기·덤불·바위 아래는 차폐로 어두움
- **움직임**: 정점 셰이더 바람 — 높을수록 크게 흔들리는 가지 + 잎 떨림 + 돌풍. **플레이어가 지나가면 풀·덤불이 옆으로 밀림** (적 병사용 칸 3개 더 있음)

### 빛·대기
- **햇빛 얼룩**: 해 쪽으로 투영한 캐노피 덮임을 문턱값으로 햇빛 얼룩 무늬를 잘라냄 → 덮임이 짙을수록 작고 드문 빛 얼룩, 해가 낮으면 해 방향으로 길쭉, 바람에 살짝 일렁임. 가까운 줄기·하층 식생은 그림자 맵
- **빛줄기**: 캐노피 틈에서 해 방향으로 늘인 카드(카메라를 향해 회전, 가산 혼합). 품질별 개수
- **환경광**: 숲 바닥은 잎을 통과한 녹색빛으로 어둡게, 바닥 차폐(AO) 격자로 줄기 밑동·덤불 아래 어두움
- **높이 안개**: 낮은 곳일수록 짙고, 숲속에서는 녹회색. 눈높이 아래 먼 줄기는 어두운 녹회색으로, 위쪽 수관·하늘은 밝은 안개로 사라져 실루엣이 겹겹이 보임. 해 쪽을 보면 안개가 밝게 산란
- **톤**: ACES 톤 매핑 뒤 채도·대비 보정, 약한 비네트

- 저지대 늪 (깊은 진흙 + 고인 물웅덩이, 가장자리 얕은 진흙 → 젖은 흙)
- 5×4칸 논: 물 찬 논과 좁은 논둑(0.6m), 가운데 넓은 주 논둑. 논둑은 바닥보다 0.28~0.32m 높아 빠르지만 노출되고, 논 안은 느리고 25cm 빠짐
- 맵을 가로지르는 오솔길 6개 (저지대 구간은 자동으로 진흙화, 시작 오솔길은 명시적으로 흙길 → 진흙길)
- 쓰러진 통나무(일부는 점프해야 넘음), 바위, 드러난 큰 뿌리, 큰 나무의 판근 — 모두 높이를 가진 지지형 장애물
- 가장자리: 북·서 절벽(35° 이상 → 오를 수 없고 미끄러져 내려옴), 남 깊은 강(가슴 이상 → 진입 불가), 동 밀집 대나무 띠(통과 불가). 투명벽은 이 뒤에 숨긴 최후 안전 경계뿐

### 분위기
- 시간대 3종(새벽 안개 / 한낮 / 해질녘), 날씨 3종(맑음 / 비 / 폭우) — 비가 올수록 젖음도가 올라 진흙 페널티·미끄러움이 커지고, 지면·껍질·바위가 번들거리고, 안개가 짙어져 시야가 줄어듦

### 이동 (사람 공용 컴포넌트 `HumanMotor`)
- `getSurfaceAt(x, z)`로 지면 판정 → 지면별 속도·스태미나·빠짐·가속도·발소리·소음 반경·바스락 반경
- 진흙 규칙: 깊은 진흙·논에서 달리기·점프 불가, 가만히 서 있으면 3초에 걸쳐 최대 50cm까지 빠짐, 다시 움직이면 최대 0.8초 발 빼는 지연 + 빨아들이는 소리, 걸음 주기에 맞춘 속도 출렁임, 빠진 만큼 카메라 하강
- 깊은 물·깊은 진흙에선 엎드리기 불가, 가슴 이상 물은 진입 불가
- 경사: 15°부터 오르막 감속, 35° 이상 못 오름, 젖은 흙·진흙 25°(젖음도가 높을수록 낮아짐) 이상에서 미끄러짐, 달리면 더 크게
- 자세 3종 + 전환 시간, 기울이기(나무·지형에 막히면 덜 기울어짐), 낮은 점프
- 스태미나: 실제 변화 = 회복 − 소모 × 지면 배율 × 무게 배율 × 오르막 배율. 0이면 30까지 달리기 불가 + 거친 숨. 수치 바 없이 숨소리·비네트·카메라 호흡 흔들림으로만 표현
- 심박수(`motor.heartRate`)와 노출도(`motor.exposure`)를 외부에서 읽을 수 있음

### 소리 (Web Audio 절차 합성)
- 지면별 발소리 11종(지피식물·덤불 추가), 식물 헤치는 바스락 소리(식물 키에 따라 커짐), 진흙 발 빼는 소리, 착지, 미끄러짐, 자세 전환
- 정글 환경음(매미·귀뚜라미·새 5종·긴팔원숭이·먼 울음·개구리·바람), 날씨 연동 빗소리·물방울, 스태미나 연동 숨소리·심장 박동
- 발소리·바스락마다 소음 이벤트(위치, 반경) 발생 → `NoiseEvents` (빗소리가 클수록 반경 감소). F3 상태에서 노란 원으로 표시

### 화면
- 조준점·체력·스태미나 바·미니맵 없음. 왼쪽 아래 흐린 자세 아이콘(아래 점 = 조용히 걷기)만 표시
- F3: FPS, 드로우콜·삼각형·화면 내 인스턴스, 좌표, 지면, 빠진 깊이, 속도, 스태미나, 심박수, 소음 반경, 노출도, 시야/탄도 레이캐스트 결과 등

### 2단계 난이도 자동 측정 (`npm run aim`, 전부 통과)
“표적 중심을 정확히 겨누되 흔들림·반동은 그대로 받는 가상 사수”가 조건마다 1,000발을 쏴서 명중률을 잽니다 (`scripts/aim-sim.mjs` — 머리말에 같은 규칙).

- 실제 모듈을 그대로 씀: `CombatSystem`(평지 월드 `createFlatWorld(0)`) + `People` + `Shooter`(`Weapon` + `AimModel`). 탄은 실제 투사체(중력·공기 저항·영점 100m·고유 산포·캡슐 판정).

### 성능

## 알려진 한계

- **4단계 — 적은 캡슐 몸입니다.** 걸을 때 다리 동작이 없어 미끄러지듯 움직이고(자세·조준·쓰러짐만 보임), 손에 든 총은 조준선에 고정된 채 보입니다.
- **정글이 빽빽해서 시각 발견은 대부분 가까이에서 일어납니다.** 매복은 주로 관측자의 시야나 kill zone 바로 옆 발소리(약 16m)로 개시됩니다. 엎드린 매복병(눈높이 0.32m)은 풀 바닥층에 가려 거의 못 보고, 구덩이 병사는 풀 위로 보려고 머리·어깨까지 내놓습니다 (사양의 ‘머리만’보다 조금 더).
- 적 시야는 1단계 시야 모델(`raycastWorld('vision')`)을 그대로 씁니다 — 위 “화면과 시야 모델이 어긋납니다” 한계가 그대로 적용됩니다 (화면에서 잎에 가려 안 보여도 적이 볼 수 있고, 그 반대도).
- 엄폐는 원기둥 충돌체(줄기)·통나무·바위·덤불만 고릅니다 — 지형 굴곡·논둑 뒤는 쓰지 않습니다. 큰 판근 줄기 사이에서 가끔 끼었다가 옆걸음·경로 재탐색으로 빠져나옵니다.
- 측면 기동은 위협 기준 각·거리로 정한 지점까지 가는 단순한 방식이라, 지형을 읽는 전술(능선 넘기·개울 따라가기)은 없습니다. 수류탄·무기 줍기·수영은 없습니다.
- 고함은 실제 언어가 아닌 외침 음절 합성이고, HRTF·총성 성격·동물 정적은 측정으로만 맞췄을 뿐 사람 귀로 들어 보지 못했습니다.
- 수치 확인은 헤드리스(게임 시간 수 분 분량)로 했고, 브라우저는 소프트웨어 렌더링(초당 몇 프레임)이라 긴 전투는 브라우저에서 끝까지 돌려 보지 못했습니다. 실제 GPU 프레임레이트도 측정하지 못했습니다 (구조적 예산만 적용).

- **3단계 — 쓰러짐은 절차 애니메이션입니다.** 선 채로 즉사하면 몸 전체가 발을 축으로 굳은 채 넘어가 경사에 맞춰 눕습니다 (무릎이 꺾이거나 팔다리가 늘어지지 않음, 물리 없음).
  앉은·엎드린 채 죽으면 엎드린 모양으로 늘어집니다. 기어가는 표적도 다리 동작 없이 미끄러지듯 움직입니다.
- **스침 판정이 팔에서 잦습니다**: 사양(표면 2cm)대로 하면 팔(반경 5cm) 명중의 절반 이상, 하완은 약 70%가 스침입니다.
- 엄폐물 찾기는 총알을 막는 줄기·바위·통나무(원기둥 충돌체)만 봅니다 — 논둑·지형 굴곡 뒤로는 숨지 않고, 찾지 못하면 쏜 쪽 반대로 기어갑니다.
- 1인칭 화면 흐림·회색은 캔버스 CSS 필터라 저사양 GPU에서 60% 미만일 때 프레임이 조금 떨어질 수 있습니다 (효과가 없으면 꺼짐).
- 부상 소리(신음·기침·처치)는 절차 합성이라 실제 목소리보다 단조롭고, 사람 귀로 들어 보지 못했습니다.
- 브라우저 확인은 소프트웨어 렌더링(초당 몇 프레임)에서 했습니다. 출혈 사망 시간(1~2분)은 헤드리스 시간으로만 쟀습니다.

- **2단계 — 실제 GPU 프레임레이트 미측정**: 소프트웨어 렌더링(초당 0.2~2프레임)만 가능해 그리기 호출·삼각형·CPU 시간으로 대신했습니다. 가까운 총구 연기의 겹침 비용은 실제 GPU에서 확인이 필요합니다.
- **가늠자·가늠쇠가 실제 비율이라 작습니다** (1280×720에서 가늠자 홈 약 10px, 가늠쇠 약 3px). 조준 시 시야각은 ×0.93만 좁힙니다(스코프 없음). 어두운 숲을 배경으로 하면 가늠쇠가 잘 안 보일 수 있습니다.
- **난이도 측정의 가상 사수**는 흔들림을 보지 않고 정해진 순간에 쏩니다. 8자 궤적이 중심을 지날 때 당기는 사람은 측정보다 잘 맞힙니다. 엎드리기·거치처럼 흔들림이 작을 때는 방아쇠 흔들림(`aim.sway.triggerJerkDeg` 0.16°)이 오차의 대부분입니다.
- 무기 무게(8.8kg) 때문에 1단계 이동 수치가 약 5~8% 느려졌습니다 (사양대로이며, README 1단계 표는 25kg 기준).
- 1인칭 소총은 별도 패스로 그려서 나무 그림자가 지지 않습니다 (숲 그늘·햇빛 얼룩은 반영). 튀어나간 탄피가 바로 옆 줄기 위로 겹쳐 보일 수 있습니다. 거치는 조준 중 총이 잠깐 내려앉는 것으로만 보입니다.
- F8 표적은 숲속에서는 나무·덤불·지형에 가려지는 경우가 많습니다 (트인 곳 권장). 걷는 표적은 다리 동작 없이 미끄러지듯 움직입니다.
- F7의 가상 사수는 플레이어 앞 30m부터만 지형·나무와 충돌합니다 (멀리서 쏜 탄이 숲에 다 막히지 않게). 대나무·잎 굴절 때문에 아주 드물게(약 0.5%) 0.25m보다 가깝게 지나갈 수 있지만 맞지는 않습니다.
  연발 간격이 짧아 F7 동안 제압은 대부분 85 이상에 머물고, 멈추면 약 11초에 0으로 돌아옵니다. 심박은 1단계 심박 모델대로 천천히(수십 초) 내려옵니다.
- 총소리는 측정값(파형·스펙트럼·잔향)으로만 맞췄고 사람 귀로 들어 보지 못했습니다. 언덕 메아리 패턴은 지형과 상관없이 고정입니다.
- 조준 8자 궤적은 들리는 숨소리와 위상이 맞춰져 있지 않습니다.
- 실제 GPU 프레임레이트는 측정하지 못했습니다 (위 “성능” 참고). 잎은 알파 테스트 카드라 고해상도·MSAA에서 겹침(overdraw) 비용이 큽니다.
- **화면 시야는 목표 범위의 하한 쪽입니다.** 헤드리스 `raycastWorld` 기준(지형이 트인 방향, 서서 중앙값 20.8m)은 15~40m 안이지만, 실제 화면 측정에서는 보이는 깊이 중앙값 16.1m(시점의 4분의 1은 8.6m 이하), 광선별 중앙값 7.5m입니다. 덤불 한가운데 서 있으면 바로 앞 잎에 가려 몇 m밖에 안 보이는 시점이 많습니다.
- **화면과 시야 모델이 어긋납니다.** 같은 방향에서 화면이 `raycastWorld('vision')`보다 일찍 막힙니다 (지형이 트인 방향 화면 9.8m vs 모델 21.6m). 4단계 적 AI가 이 모델을 그대로 쓰면, 플레이어 화면에서는 잎에 가려 안 보이는 거리에서도 적이 플레이어를 볼 수 있습니다. 식생 밀도(`vegetation.*Spacing`, `thicketThreshold`)나 소광계수(`vegetation.coverProfiles`)로 둘을 다시 맞춰야 합니다.
- 판근·줄기는 메시와 물리 판근(캡슐 2토막)이 같은 능선 식을 쓰지만, 판근 아래쪽 넓게 퍼진 부분은 물리에 없어 발이 살짝 파묻혀 보일 수 있습니다.
- 수관 잎은 그림자 맵에 그리지 않고 햇빛 얼룩 무늬로 대신합니다 (얼룩이 실제 잎 위치와 1:1로 맞지는 않음). 그림자 맵은 플레이어 주변 줄기·하층 식생만 그립니다.
- 식물 밀림은 셰이더 변위라 충돌·소리와 별개이며, 지피층·덤불·풀·하층 잎에만 적용됩니다 (큰 나무 수관 제외).
- 안티에일리어싱(따라서 `alphaToCoverage`)은 시작 시 품질로 정해집니다 (‘낮음’으로 시작하면 꺼짐, 바꾸려면 새로고침).
- 바위 충돌은 타원체 근사라 울퉁불퉁한 표면과 몇 cm 어긋날 수 있습니다. 통나무 넘기는 “점프 + 디딤” 방식입니다.
- 소리는 절차 합성이라 실제 녹음보다 단조롭습니다. 플레이어 자신의 발소리·숨소리는 머리 위치 소리라 3D 위치 없이 재생합니다 (적 발소리는 같은 합성을 HRTF 위치로).
- 시야 레이캐스트(`vision`)는 식생·지형만 따지고 안개·밤·날씨는 반영하지 않습니다 (4단계 적은 여기에 1단계 노출도 — 빛 포함 — 를 곱해 씀).
- 늪은 대부분 얕게 고인 물 아래 깊은 진흙이라 겉보기엔 물처럼 보입니다 (발소리와 빠짐으로 구분됨).
